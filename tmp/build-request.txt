Build Request: Automatic Post­Customer
Acceptance Sales Work ow

Implement the work ow that starts when a customer accepts an approved Sales Order.

Do not redesign the existing Sales Order ow. Add automatic work ow task creation, status
changes, noti cations and audit history after the event Customer Accepted.

Core rule

A Sales Order may be customer-accepted only after:

  1. Sales has created it.

  2. Warehouse has con rmed stock availability.

  3. Checker has approved it.

  4. Sales has shared it with the customer.

  5. Customer acceptance has been recorded.

When the Sales Order status changes to CUSTOMER_ACCEPTED, the system must automatically
create the next task based on the payment term selected on that Sales Order.

Payment-term branches

Branch 1 -- Net credit terms

Examples: Net 30, Net 45, Net 60.

When Sales Order becomes CUSTOMER_ACCEPTED:

  1. Automatically create a Finance task:

          Task title: Create Final Sales Invoice

          Linked document: Sales Order

          Assigned role: Finance

          Status: Open

          Due date: same day, unless con gured otherwise.
  2. Change Sales Order status to:

  3. Do not wait for customer payment before invoice or dispatch preparation.
Branch 2 -- 100% advance

When Sales Order becomes CUSTOMER_ACCEPTED:

  1. Automatically create a Finance task:
          Task title: Create Proforma Invoice for Advance
          Linked document: Sales Order
          Assigned role: Finance

  2. Change Sales Order status to:

          AWAITING_ADVANCE_PAYMENT

  3. Do not create a Final Invoice task yet.
  4. Do not create a Warehouse Dispatch task yet.

After Finance creates and sends the Proforma:

  1. Create a Treasury task:
          Task title: Confirm Customer Advance Receipt
          Linked documents: Sales Order and Proforma
          Assigned role: Treasury

When Treasury marks the full advance as received:

  1. Automatically create a Finance task:
          Task title: Create Final Sales Invoice
          Linked document: Sales Order and Proforma
          Assigned role: Finance

  2. Change Sales Order status to:

          READY_FOR_INVOICE
